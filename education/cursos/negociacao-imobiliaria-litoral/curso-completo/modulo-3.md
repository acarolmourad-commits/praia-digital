# Módulo 3 — Proposta e Flexibilidade

## Introdução
Aprenda a montar proposta, usar flexibilidade e fechar negociações no litoral.

## Aula 3.1 — Proposta
**Proposta:**
- Dados.
- Valor.
- Condições.

**Exemplo real:**
Corretor fechou negociação com proposta clara.

## Aula 3.2 — Flexibilidade
**Flexibilidade:**
- Prazo.
- Forma.
- Condições.

**Exercício:**
Monte uma proposta negociável.

## Aula 3.3 — Fechamento
**Fechamento:**
- Contrato.
- Assinatura.
- Registro.

**Estudo de caso:**
Corretor fechou negociação rápida com método.

## Resumo
- Proposta define valor.
- Flexibilidade reduz conflito.
- Fechamento depende de método.
