# Controle de leads — template

## Estrutura
Criar planilha/CSV com as colunas abaixo.

## Colunas
- Lead
- Segmento (Airbnb/Booking, Corretor, Imobiliária, Proprietário, Administrador)
- Cidade
- Serviço (Fotografia, Edição, Combo)
- Canal (WhatsApp, E-mail, Site)
- Contato
- Status
- Origem
- Data contato
- Próxima ação

## Status
- Novo
- Contatado
- Respondeu
- Diagnóstico
- Orçamento
- Negociação
- Fechado
- Perdido

## Regras
- Atualizar status imediatamente após cada interação
- Todo lead em “Diagnóstico” deve ter data de entrega do diagnóstico
- Follow-up automático apenas após 24h sem resposta
- Máximo de 3 follow-ups antes de arquivar como “Perdido”
