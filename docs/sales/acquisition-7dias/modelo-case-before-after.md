# Modelo de case antes/depois

## Estrutura do case

### Antes
- Screenshot do anúncio original
- Título original
- Descrição original (resumo)
- Problemas identificados:
  - [ ] Título genérico
  - [ ] Foto principal ruim
  - [ ] Descrição longa sem estrutura
  - [ ] Falta de diferenciais

### Depois
- Novo título
- Nova descrição estruturada
- Ordem das fotos sugerida
- Destaques aplicados

### Resultado
- [Medir após 15–30 dias]
- Contatos recebidos: X
- Reservas/fechamentos: Y
- Tempo de fechamento: Z

## Template de aprovação/autorização

> Olá! Podemos usar o antes/depois do seu anúncio como case comercial?
>
> Em troca, podemos destacar o nome do imóvel ou da imobiliária (ou manter anônimo, se preferir).
>
> Sem compromisso — se não quiser, não usamos.

## Uso permitido
- Site (página de cases)
- Redes sociais
- Propostas comerciais
- Materiais de vendas

## Armazenamento
Salvar em:
- `docs/sales/cases/[cliente]-antes-depois.md`
- Imagens em `docs/sales/cases/img/[cliente]-antes.png`
- Imagens em `docs/sales/cases/img/[cliente]-depois.png`
