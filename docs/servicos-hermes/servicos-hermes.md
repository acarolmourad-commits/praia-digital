# Serviços — Agente Hermes
Visão comercial do serviço de implantação/manutenção do Agente Hermes para operações reais.

- **Instalação**: setup do Hermes, configuração inicial e integração com ferramentas do negócio.
- **Configuração personalizada**: prompts, fluxos, automações e conexões conforme o operação.
- **Manutenção contínua**: atualizações, ajustes de desempenho, correções e suporte técnico.
