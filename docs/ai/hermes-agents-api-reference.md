# API Reference — Hermes Agents

> Documentação técnica da API.

## Base URL
https://api.praia.digital/v1

## Autenticação
Authorization: Bearer <token>

## Endpoints

### Criar agente
POST /agents

### Enviar mensagem
POST /agents/{id}/messages

## Status codes
- 200 OK
- 201 Created
- 400 Bad Request
- 401 Unauthorized
