# Playbook de Suporte — Hermes Agents

> Guia para equipe de suporte ao cliente.

## Canais
- WhatsApp: suporte técnico e dúvidas
- E-mail: issues complexas e SLA
- Telefone: urgências

## SLAs
- Crítico: 1h resposta
- Alto: 4h resposta
- Médio: 24h resposta
- Baixo: 48h resposta

## Troubleshooting
1. Agente não responde → verificar webhook
2. Resposta errada → ajustar base de conhecimento
3. Integração quebrada → verificar API keys
4. Performance lenta → verificar rate limits
