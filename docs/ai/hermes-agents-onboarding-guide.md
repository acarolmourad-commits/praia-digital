# Guia de Onboarding — Hermes Agents

> Processo de onboarding para novos clientes.

## Fase 1: Diagnóstico (Dia 1)
- Reunião de discovery
- Mapeamento de dores
- Definição de KPIs

## Fase 2: Configuração (Dias 2-3)
- Setup do agente
- Integração com canais
- Base de conhecimento

## Fase 3: Validação (Dias 4-5)
- Testes com dados reais
- Ajustes de tom/voz
- Treinamento da equipe

## Fase 4: Go-live (Dia 6)
- Deploy gradual
- Monitoramento 24h
- Ajustes pós-launch

## Fase 5: Otimização (Semana 2+)
- Análise de métricas
- Ajustes de fluxo
- Expansão de canais
