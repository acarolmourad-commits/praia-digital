## 11. Análise Hub vs página principal

Opção A — página editorial principal "Documentação imobiliária"
- Vantagem: resposta direta para intenção genérica
- Risco: canibalização com guias específicos; risco SEO se profundidade for baixa
- Esforço: médio
- Potencial SEO: médio-alto se houver conteúdo robusto
- Potencial comercial: médio

Opção B — hub de documentação imobiliária
- Vantagem: organizar subpáginas existentes; reduzir canibalização; criar arquitetura clara
- Risco: esforço alto; risco de sobreposição antes das canibalizações médias estarem resolvidas
- Esforço: alto
- Potencial SEO: alto a longo prazo
- Potencial comercial: alto se bem estruturado

Opção C — fortalecer uma página existente
- Vantagem: menor risco; reutiliza URL existente; evita canibalização inicial
- Risco: pode limitar crescimento se a página ficar sobrecarregada
- Esforço: baixo a médio
- Potencial SEO: médio
- Potencial comercial: médio

Recomendação:
Opção C — fortalecer `blog/documentacao-completa-imovel-2026.html` como página central leve, sem criar hub agora.
