# Modelo editorial 4 velocidades — Praia Digital
Data: 2026-08-16
Status: Modelo aprovado
D2: SEM IMPACTO

## Princípio

Uma página é classificada pela velocidade com que sua informação perde validade, não pelo formato.

Objetivo: transformar o portal em um sistema editorial vivo sem criar conteúdo artificial.

## 1. EVERGREEN

### O que é
Conteúdo permanente, conceitual, tutorial, de base.

### Exemplos
Guias
Conceitos
Tutoriais
Financiamento
Compra/venda
Investimento
Proprietário

### Regras
- Sem data de validade
- Atualizar quando houver mudança substantiva
- Não inventar dados
- Fontes quando aplicável
- Links internos obrigatórios
- CTA contextual

## 2. ATUALIZADO

### O que é
Conteúdo que muda periodicamente, mas não diariamente.

### Exemplos
Mercado
Preços
Legislação
Turismo
Bairros
Cidades
Temporada
Indicadores

### Regras obrigatórias
- "Atualizado em DD/MM/AAAA"
- Fonte quando aplicável
- Metodologia quando aplicável
- Indicar claramente o período dos dados
- Não apresentar dado antigo como atual
- Revisar periodicamente

## 3. NOTÍCIA

### O que é
Acontecimentos recentes, fatos novos.

### Exemplos
Mercado
Eventos
Turismo
Políticas públicas
Infraestrutura

### Regras obrigatórias
- Data/hora da publicação
- Fonte confiável
- Distinção clara entre notícia e opinião/análise
- Nunca inventar fato
- Corrigir erros publicamente
- Não confundir com análise

## 4. ANÁLISE

### O que é
Interpretação de dados, tendências, comportamento.

### Exemplos
Tendências
Interpretação de dados
Investimento
Comportamento do mercado
Sazonalidade
Estudos locais

### Regras obrigatórias
- Separar dado factual de interpretação
- Separar interpretação de conclusão
- Fontes de dados
- Metodologia
- Data de publicação
- Limitações da análise
- Não confundir com notícia

## 5. TEMPO REAL

### O que é
Camada viva do Portal Agora.

### Elementos
Clima + mar + eventos + notícias + mercado + imóveis + temporada

### Regras obrigatórias
- Timestamp obrigatório
- Fonte obrigatória
- Nunca inventar dado
- Quando indisponível, mostrar "dado indisponível"
- Atualização documentada
- Integração futura com APIs

## Regra de ouro

Não transformar todo conteúdo em "notícia".

Uma página é classificada pela velocidade com que sua informação perde validade.

Não criar quantidade fixa de notícias por dia.

1 notícia realmente relevante > 20 publicações artificiais.

## Primeiro lote

Evergreen: 2
Atualizado: 2
Notícia: 2
Análise: 1
Tempo Real: 1 atualização no Santos Agora

Total: 8 peças

Depois medir:
- qualidade
- atualização
- fontes
- links internos
- indexabilidade
- tempo de manutenção
- potencial de tráfego
- potencial comercial

## Arquitetura de links

Evergreen → Atualizado → Notícia → Análise → Tempo Real

Links cruzados sempre que relevante.

Usuário deve poder sair de uma informação pontual e chegar ao conteúdo aprofundado.
