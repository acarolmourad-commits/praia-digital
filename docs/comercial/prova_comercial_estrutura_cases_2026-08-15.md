# Prova Comercial — Estrutura de cases
Data: 2026-08-15
Tipo: estrutura / regra
Regra: nunca inventar resultado; nunca afirmar causalidade sem dados

## Formato

### ANTES
- anúncio
- pontuação
- problemas encontrados
- contexto

### INTERVENÇÃO
- edição
- título
- descrição
- fotos
- posicionamento
- preço
- calendário
- diferenciais

### DEPOIS
Registrar somente dados reais:
- visualizações
- cliques
- consultas
- reservas
- conversão
- ocupação
- receita
- avaliações

## Regras

- Nunca inventar resultado
- Nunca afirmar causalidade quando os dados não permitirem
- Primeiro construir evidência
- Todo case deve ter:
  - data
  - identificador do imóvel/anúncio
  - dados antes
  - intervenção
  - dados depois
  - fonte dos dados
  - observações

## Estado

Aguardando primeiros dados reais de edição e desempenho.
