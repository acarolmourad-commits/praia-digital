# Framework de classificação de 404 — Praia Digital
Data: 2026-08-18

## Categorias
A. 404 legítimo/intencional
B. link quebrado
C. página removida que precisa de redirect
D. URL digitada incorretamente
E. referência antiga
F. recurso inexistente que deve ser removido

## Critérios de classificação
- Se a página foi removida intencionalmente e não há substituta: A
- Se o link aponta para um caminho errado: B ou D
- Se havia uma página anterior e ela foi movida: C
- Se é uma URL antiga sem correspondência atual: E
- Se é um arquivo/css/js/imagem que não existe mais: F

## Regras de reparo
- C: corrigir link para URL correta OU implementar redirect quando houver substituta inequívoca
- B/D: corrigir a referência
- E: remover referência quebrada se não houver substituta segura
- F: remover referência
- A: manter como está
- Nunca redirecionar tudo para homepage sem justificativa

## Validação pós-reparo
- HTTP 200 da nova URL
- canonical correto
- ausência de cadeia de redirects desnecessária
- links internos atualizados
- sitemap coerente

## Documentação
- Registrar todos os 404 encontrados
- Registrar todos os reparos realizados
- Registrar pendências que exigem decisão humana
