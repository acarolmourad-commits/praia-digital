# Template de handoff humano — Motor A
Uso: acionado quando houver resposta positiva, pedido de preço ou agendamento.

## Formato obrigatório
SERVIÇO → VALOR POTENCIAL → ESTÁGIO → PRÓXIMA AÇÃO → RESPONSÁVEL

## Exemplos

### Resposta positiva genérica
- SERVIÇO: Edição de anúncio / Administração Airbnb / Fotografia imobiliária
- VALOR POTENCIAL: R$ 497 / 10–15% da taxa / R$ 700+
- ESTÁGIO: Interesse confirmado
- PRÓXIMA AÇÃO: comercial@praia.digital / (11) 95434-6288
- RESPONSÁVEL: Carolina / equipe comercial

### Pedido de preço
- SERVIÇO: conforme necessidade principal do lead
- VALOR POTENCIAL: conforme tabela fechada
- ESTÁGIO: Aguardando envio de proposta
- PRÓXIMA AÇÃO: Responder com preço aprovado
- RESPONSÁVEL: Equipe comercial

### Pedido de agendamento
- SERVIÇO: conforme interesse
- VALOR POTENCIAL: conforme serviço
- ESTÁGIO: Agendamento pendente
- PRÓXIMA AÇÃO: Confirmar disponibilidade
- RESPONSÁVEL: Carolina / equipe comercial

## Regras
- Não enviar proposta genérica; sempre personalizar com observação específica do anúncio/perfil
- Cross-sell obrigatório após venda/interesse
- Registrar resposta no CRM imediatamente após classificação
- Não prosseguir com follow-up automático após handoff
