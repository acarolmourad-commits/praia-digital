# Sequência de follow-up — São Sebastião + Bertioga
Regra: parar se houver resposta negativa, pedido de não contato, bloqueio ou desinteresse.

## D0 — Primeira abordagem
Objetivo: apresentar observação específica + problema + solução + próximo passo.
Canal: WhatsApp/e-mail público quando disponível; caso contrário, deixar como AÇÃO_HUMANA_PENDENTE.

Template base D0:
"Olá, vi [evidencia especifica do anuncio/perfil]. O imovel tem potencial, mas [problema especifico]. Nosso servico [solucao] inclui [entregaveis]. Posso te mostrar como melhoraria essa apresentacao?"

## D2 — Follow-up curto
Objetivo: relembrar sem pressionar.
Template base D2:
"Olá, passando para lembrar que podemos melhorar [ponto especifico] e ajudar a aumentar [beneficio]. Se quiser, envio um exemplo rapido."

## D5 — Nova abordagem com benefício
Objetivo: trazer valor novo.
Template base D5:
"Olá, uma dica rapida: [beneficio tangivel]. Se fizer sentido, posso preparar uma sugestao objetiva para [imovel/bairro]."

## D10 — Última tentativa
Objetivo: fechar ou seguir para nutrição.
Template base D10:
"Olá, última mensagem por aqui: se [problema] fizer sentido no momento, me avise. Caso contrario, posso manter contato para quando for oportuno."

## Depois de D10 → Nutrição
Sem novas abordagens até nova oportunidade comercial.
