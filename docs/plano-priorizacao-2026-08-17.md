# Plano P0 / P1 / P2 — Praia Digital

## P0
- Clareza de marca: separar “Praia Digital proprietário” de “Praia Digital imobiliária/IA”
- Fluxo de checkout: ausência de integração cobrança → entrega
- Links repetidos quebrados com regra de correção determinística
- Acessibilidade: bloqueios críticos, se houver

## P1
- Segmentação automática por `interesse` no formulário/WhatsApp
- Schema/meta/h1 auditados por script
- Melhoria da página de serviços com separação por perfil
- Experiência mobile: testes de viewport e interação

## P2
- Conteúdo complementar: revisão de duplicidade temática
- Métricas automáticas pós-entrega
- Otimizações de performance

## Ações automatizáveis
- Segmentação por `interesse`
- Correção de links por regra
- Auditoria SEO automatizada
- Integração checkout

## Ações que exigem humano
- IA: briefing, proposta, negociação, implantação
- Revisão de conteúdo editorial e duplicidade
- Decisão de separação de marca
- Autorização para correção de links

## Dependências
- Gateway de pagamento para checkout
- Autorização para separação de marca
- Autorização para normalização dos 64 cursos

## Sequência ideal
1. P0: marca, links repetidos, checkout
2. P1: segmentação, schema audit, mobile
3. P2: conteúdo, métricas, performance
