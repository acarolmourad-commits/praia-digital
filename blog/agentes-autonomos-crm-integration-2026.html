1. Por que integrar?

Quando o agente qualifica um lead no WhatsApp/Telegram, ele já cria/atualiza o contato no CRM automaticamente — sem intervenção humana.

2. Arquitetura

Camada de ingestão → Orchestrator → Conector CRM (webhook/API) → CRM. O agente decide quando sincronizar baseado em regras.

3. CRM suportados

  • HubSpot — API REST + webhooks. Criar contato + deal + nota.
  • RD Station — API v2. Criar lead + tag + funil.
  • Pipedrive — API REST. Criar pessoa + deal + atividade.
  • Salesforce — REST API + Apex triggers. Sincronizar conta + oportunidade.

4. Exemplo de código

def create_hubspot_contact(name, email, phone, source):
    url = "https://api.hubapi.com/crm/v3/objects/contacts"
    headers = {"Authorization": f"Bearer {HUBSPOT_TOKEN}", "Content-Type": "application/json"}
    data = {
        "properties": {
            "firstname": name.split()[0],
            "email": email,
            "phone": phone,
            "hs_lead_status": "NEW",
            "hs_source": source
        }
    }
    r = requests.post(url, json=data, headers=headers)
    return r.json()

5. Melhores práticas

  • Usar webhooks para eventos de CRM → agente (ex: deal ganho → mensagem WhatsApp).
  • Idempotência: deduplicar leads por e-mail/telefone.
  • Logs estruturados para auditoria.
  • Testar em staging antes de produção.
